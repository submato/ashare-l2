# A-Share Level-2 Schema

日分区 Wind 风格 CSV。磁盘编码多为 **GBK**（样例 `DEMO.SZ` 为 UTF-8）。

## 目录

```text
data/{SYMBOL}/l2/YYYYMMDD/
  行情.csv
  逐笔委托.csv
  逐笔成交.csv
```

## 通道

| 文件 | 含义 |
|------|------|
| `行情.csv` | 十档买卖盘快照 |
| `逐笔委托.csv` | 逐笔委托 |
| `逐笔成交.csv` | 逐笔成交 / 撤单 |

## 行情关键字段

万得代码、自然日、时间、成交价/量/额、申买价1..10、申买量1..10、申卖价1..10、申卖量1..10、前收盘/开盘价/最高价/最低价。

## 逐笔委托关键字段

交易所委托号、委托代码（B/S 等）、委托价格、委托数量、委托类型。

## 逐笔成交关键字段

成交编号、成交代码（成交/撤单）、BS标志、成交价格、成交数量、叫卖序号、叫买序号。

Wind 导出价格常见为整数 ×10000（如 `420900` → `42.09`），使用前请按你的数据源确认。
