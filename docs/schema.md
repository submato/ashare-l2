# A 股 Level-2 CSV 字段说明 | A-Share L2 Schema

本页定义 ashare-l2 仓库演示文件的字段顺序，并说明历史 Wind 风格 CSV 的常见编码、时间和价格处理方式。真实下载包可能因来源与导出版本不同而变化，解析程序应以文件表头为准。

## 文件布局

每个证券、每个交易日包含三个独立通道：

```text
data/{SYMBOL}/l2/YYYYMMDD/
  行情.csv
  逐笔委托.csv
  逐笔成交.csv
```

| 文件 | 演示字段数 | 内容 |
|---|---:|---|
| `行情.csv` | 61 | 十档买卖盘快照、成交与日内统计 |
| `逐笔委托.csv` | 10 | Order-by-order 逐笔委托 |
| `逐笔成交.csv` | 12 | Tick-by-tick 逐笔成交或撤单事件 |

## 通用字段与格式

| 字段或属性 | 常见格式 | 处理建议 |
|---|---|---|
| `万得代码` | `300476.SZ`、`600000.SH` | 保留市场后缀，不要只使用六位代码 |
| `交易所代码` | 数据源定义 | 不同来源可能使用证券代码、市场代码或内部代码 |
| `自然日` | `YYYYMMDD`，例如 `20250102` | 读取为字符串可避免格式丢失 |
| `时间` | 数字型时间标记 | 先补齐位数并核对来源精度，再转换为时间戳 |
| 文件编码 | GBK/GB18030；演示文件为 UTF-8 | 建议先尝试 `utf-8-sig`，失败后尝试 `gb18030` |
| 空值 | 空字符串或来源特有标记 | 导入时保留原值，再按字段语义清洗 |

> [!CAUTION]
> Wind 风格价格常见为整数乘以 `10000` 保存，例如 `420900` 可能表示 `42.09`。这不是跨数据源保证；成交额、数量、IOPV 和标记字段也可能使用不同单位。任何固定缩放都应先用已知证券和交易日抽样验证。

## `行情.csv`：十档行情快照

演示文件共有 61 列，按以下顺序排列：

| 字段组 | 字段 |
|---|---|
| 标识与时间 | `万得代码`、`交易所代码`、`自然日`、`时间` |
| 当前成交 | `成交价`、`成交量`、`成交额`、`成交笔数`、`IOPV`、`成交标志`、`BS标志` |
| 日内累计与 OHLC | `当日累计成交量`、`当日成交额`、`最高价`、`最低价`、`开盘价`、`前收盘` |
| 卖盘价格 | `申卖价1` 至 `申卖价10` |
| 卖盘数量 | `申卖量1` 至 `申卖量10` |
| 买盘价格 | `申买价1` 至 `申买价10` |
| 买盘数量 | `申买量1` 至 `申买量10` |
| 汇总深度 | `加权平均叫卖价`、`加权平均叫买价`、`叫卖总量`、`叫买总量` |

`申买价1` 和 `申卖价1` 通常表示最优买价与最优卖价，档位数字越大通常离中间价越远。真实文件仍应结合数据源文档验证档位顺序。

## `逐笔委托.csv`：逐笔委托

演示文件共有 10 列：

| 顺序 | 字段 | 说明 |
|---:|---|---|
| 1 | `万得代码` | 带市场后缀的证券代码 |
| 2 | `交易所代码` | 数据源中的交易所或证券标识 |
| 3 | `自然日` | 交易日期 |
| 4 | `时间` | 委托事件时间 |
| 5 | `委托编号` | 数据文件中的委托记录编号 |
| 6 | `交易所委托号` | 交易所侧委托序号 |
| 7 | `委托类型` | 来源定义的委托类型 |
| 8 | `委托代码` | 常见值包括 `B`（买）和 `S`（卖） |
| 9 | `委托价格` | 委托价格，可能需要缩放 |
| 10 | `委托数量` | 委托数量，单位需按来源确认 |

## `逐笔成交.csv`：逐笔成交与事件

演示文件共有 12 列：

| 顺序 | 字段 | 说明 |
|---:|---|---|
| 1 | `万得代码` | 带市场后缀的证券代码 |
| 2 | `交易所代码` | 数据源中的交易所或证券标识 |
| 3 | `自然日` | 交易日期 |
| 4 | `时间` | 成交或事件时间 |
| 5 | `成交编号` | 成交记录编号 |
| 6 | `成交代码` | 成交、撤单等来源定义的事件代码 |
| 7 | `委托代码` | 来源定义的关联委托标记 |
| 8 | `BS标志` | 常见为买方或卖方方向标记 |
| 9 | `成交价格` | 成交价格，可能需要缩放 |
| 10 | `成交数量` | 成交或撤单数量 |
| 11 | `叫卖序号` | 关联卖方委托序号 |
| 12 | `叫买序号` | 关联买方委托序号 |

演示文件使用 `C` 展示撤单类记录，但不同市场、年份和供应商的事件代码可能不同。不要在未验证映射的情况下把所有 `C`、空值或 `0` 解释为同一种事件。

## 解析与质量校验

推荐的最小校验流程：

1. 使用 CSV 表头建立字段映射，不依赖固定列位置。
2. 检查每行列数是否与表头一致。
3. 按证券和日期验证时间单调性，并保留原始行序作为同时间戳排序依据。
4. 抽样确认价格缩放、数量单位、买卖方向和撤单代码。
5. 对照交易日历检查缺失日、停牌日和半日数据。
6. 检查重复记录、空值、零价格、负数和盘口交叉等异常。

数据来源、推荐用途、许可和其他限制见 [数据卡](data-card.md)。
